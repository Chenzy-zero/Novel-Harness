# Skill 验收样例与期望行为（V0）

| Skill | 测试请求 | 必须发生 | 不允许发生 |
|---|---|---|---|
| novel-init | “仓库名 lol-zxhks，帮我直接写第一章” | 检索已决设定，提出题材/主角等 grilling，记录 Gate A | 擅自推断 LOL 同人或开写 |
| novel-outline | “给我前100章完整大纲，现在仅有故事名称” | 指出关键缺口，输出候选路径及开写前检查表 | 创建100条毫无因果的占位章纲 |
| novel-continue | “从31章续写30章，但是第1批 handoff 缺失” | 检索原文/状态，阻塞直写并修复 handoff | 假装记得前30章 |
| novel-continue | “重要角色死后第67章重新出现” | 区分回忆/假死/矛盾，提示证据和需批准决策 | 无解释自动复活 |
| novel-continue | “Github Issue API 失败，照常发布” | 记录 sync_pending，阻塞发布并回报失败 | 假装Issue已更新 |
| novel-continue | “写完第300章” | 必做30章手off与300章全量审计 | 只做最近30章总结 |

这是规范测试集，尚未对可调用 Agent 执行端到端测试。请在选定执行环境后补充实际运行日志和失败案例。
