# Grilling 协议 / 有雾必问

## 什么时候问
- 未决定题材、时代、主角动机、能力限制、终局方向。
- 准备不可逆的核心反转、阵营切换、重要人物生死、作者未批准的重大关系发展。
- 真实正文与已批准设定冲突、缺乏因果才能推进下一章、伏笔兑现会破坏世界规则。
- 一些小细节无碍主线：可给出 `PROPOSED` 方案，但不得写入 `APPROVED`。

## 如何问
1. 说明**当前已知**、精确缺口和受影响范围。
2. 给 2–3 个故事上明显不同的方案：优点、代价、会影响的剧情弧。
3. 说明推荐哪一个及理由，但不代替作者批准。
4. 优先一次问 2–4 个**耦合问题**，避免把全部小设定都变成问卷；不重复作者已答。
5. 用户回复后落盘 `project/decisions.md`，更新 `project/questions.md` 与相应 bible/outline。
6. 重要事项无回复则 `BLOCKED`；不得继续出版受影响章节。
